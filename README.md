# 부산 아파트 매매가격 V1.1 — 웹앱 배포형

이 버전은 `index.html`을 휴대폰에서 직접 여는 방식이 아니라 **웹 서버에 배포해서 URL로 접속하는 구조**입니다.

### 포함
- 모바일 최적화 UI
- 부산 16개 구·군
- 국토교통부 아파트 매매 실거래가 API 서버 프록시
- 아파트 검색
- 최근 실거래 조회
- 호가 직접 입력 및 서버 저장(SQLite)
- 데이터 업데이트
- Docker/Render 배포 설정

### 배포
가장 간단한 방법은 Render 같은 Node/Docker 호스팅에 이 프로젝트를 올리는 것입니다.

환경변수:
`DATA_GO_KR_SERVICE_KEY` = 공공데이터포털 서비스키

배포가 완료되면 Render가 발급하는 `https://...onrender.com` 주소를 휴대폰에서 열면 됩니다.

### 보안
서비스키는 절대로 `public/`의 JS에 넣지 않습니다. 서버 환경변수에만 넣으세요.
이미 채팅에 공유한 키는 실제 서비스 전에는 재발급/교체하는 것을 권장합니다.

### 데이터 저장
V1.1은 SQLite를 사용합니다. 호스팅 환경에서 영구 저장이 필요하면 다음 단계에서 PostgreSQL/Supabase 등 외부 DB로 교체하는 것을 권장합니다.
